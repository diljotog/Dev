# DevLearn MVP

A responsive starter web app for a beginner-first technology learning platform.

## Included
- Course dashboard
- Search
- HTML, CSS, JavaScript, Python, C, C++, Java, SQL, Git, React, Node.js and Cybersecurity tracks
- Progress bars
- Roadmap UI
- Mobile responsive layout

## Run
Open `index.html` in a browser.
